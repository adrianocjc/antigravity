📄 Schema SQL Completo do Sistema (DDL)

Você pode copiar o código abaixo e rodar em qualquer banco SQL como SQLite, MySQL ou PostgreSQL:

CREATE TABLE pratos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nome VARCHAR(100) NOT NULL,
    categoria VARCHAR(50) NOT NULL,
    descricao TEXT,
    calorias INT DEFAULT 0,
    proteinas_g DECIMAL(5,1) DEFAULT 0.0,
    contem_gluten BOOLEAN DEFAULT FALSE,
    contem_lactose BOOLEAN DEFAULT FALSE,
    eh_vegetariano BOOLEAN DEFAULT FALSE
);

CREATE TABLE avaliacoes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    cardapio_id INT NOT NULL,
    prato_id INT,
    nota INT CHECK(nota BETWEEN 1 AND 5),
    categoria_feedback VARCHAR(50),
    comentario TEXT,
    tipo_usuario VARCHAR(30) DEFAULT 'Aluno',
    data_avaliacao DATETIME DEFAULT CURRENT_TIMESTAMP
);

ℹ️ Sobre o Projeto NutriEscolar

Este site foi desenvolvido com as tecnologias web mais simples e eficientes para solucionar um desafio comum nas escolas: a transparência do cardápio escolar e o engajamento dos estudantes na avaliação nutricional.

🛠️ Tecnologias Utilizadas (100% Gratuitas)

  • HTML5: Estrutura semântica e acessível da aplicação.
  • CSS3: Estilização moderna com CSS Variables, Flexbox, CSS Grid, e modo escuro/claro automático.
  • JavaScript (ES6): Manipulação de DOM, cálculos de médias, interatividade e motor SQL simulação.
  • SQL (Database): Scripts padronizados em ANSI SQL compatíveis com SQLite, MySQL e PostgreSQL.

🚀 Como Hospedar Grátis

Você pode subir este site gratuitamente em plataformas como GitHub Pages, Netlify ou Vercel sem pagar nada! Para o banco de dados SQL em nuvem gratuita, você pode usar o Supabase, PlanetScale ou Render.com com SQLite.
