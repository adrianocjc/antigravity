💾 Terminal & Banco de Dados SQL

Execute consultas SQL reais nas tabelas de usuários, pratos e necessidades alimentares.

📥 Baixar Arquivo database.sql

📄 Schema SQL Completo do Sistema (DDL)

Você pode copiar o código abaixo e rodar em qualquer banco SQL como SQLite, MySQL ou PostgreSQL:

CREATE TABLE usuarios (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nome VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    senha VARCHAR(100) NOT NULL,
    tipo_usuario VARCHAR(30) NOT NULL DEFAULT 'Aluno',
    turma_setor VARCHAR(50)
);

CREATE TABLE necessidades_alimentares (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    usuario_id INTEGER NOT NULL UNIQUE,
    intolerancia_lactose BOOLEAN DEFAULT FALSE,
    restricao_gluten BOOLEAN DEFAULT FALSE,
    vegetariano BOOLEAN DEFAULT FALSE,
    vegano BOOLEAN DEFAULT FALSE,
    diabetes BOOLEAN DEFAULT FALSE,
    alergia_amendoim BOOLEAN DEFAULT FALSE,
    alergia_frutos_mar BOOLEAN DEFAULT FALSE,
    alergia_ovo BOOLEAN DEFAULT FALSE,
    alergia_corantes BOOLEAN DEFAULT FALSE,
    outras_alergias TEXT,
    observacoes_medicas TEXT,
    contato_emergencia VARCHAR(100),
    FOREIGN KEY (usuario_id) REFERENCES usuarios(id)
);

ℹ️ Sobre o Projeto NutriEscolar

Este site foi desenvolvido para solucionar a transparência do cardápio escolar, permitir a avaliação dos estudantes e garantir um **portal privado para cadastro de necessidades alimentares**, assegurando o acompanhamento pela **Gestão e Coordenação Escolar**.

🛠️ Recursos do Sistema

  • Portal do Usuário: Login e senha individuais para Alunos, Professores e Servidores informarem suas alergias e dietas.
  • Painel da Gestão (Admin): Visão administrativa completa para a coordenação e equipe da cozinha consultarem fichas de saúde alimentar.
  • Consulta de Cardápio: Cardápio diário com selos de vegetariano, sem glúten e sem lactose.
  • Avaliação & Estatísticas: Média de satisfação dos pratos servidos.
